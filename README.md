# UPI-Fraud-Detection-System-
A machine learning-based UPI Fraud Detection System built using Python, Flask, HTML, and CSS to analyze digital transactions, identify suspicious activities, and predict potential fraud in real time.
UPI Fraud Detection System

Project Overview

The UPI Fraud Detection System is a machine learning-based web application designed to detect potentially fraudulent Unified Payments Interface (UPI) transactions.

The system analyzes transaction details such as transaction amount, time, account age, device trust score, and geographical distance to predict whether a transaction is legitimate or potentially fraudulent.

Key Features

- Machine learning-based fraud prediction
- UPI transaction simulation
- Fraud risk assessment
- User-friendly web interface
- Transaction history and fraud status display
- Flask-based backend API
- Transaction analysis using Python and Pandas

Technologies Used

- Frontend: HTML, CSS, Tailwind CSS
- Backend: Python, Flask
- Machine Learning: Scikit-learn, Pandas, NumPy
- Development Tools: VS Code, Jupyter Notebook

Project Objective

To develop an intelligent fraud detection system that helps identify suspicious UPI transactions, improves digital payment security, and demonstrates the practical application of machine learning in financial cybersecurity.

Disclaimer

This is an academic mini project intended for educational purposes. Fraud predictions are based on the trained model and available transaction data, not live banking or UPI network verification.
